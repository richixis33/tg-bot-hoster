# 💼 Telegram Business Crypto Bot

> **Официальный Telegram Business бот**, который подключается к вашему личному Telegram-аккаунту (через раздел **Telegram Business ➜ Чат-боты**) и работает в ваших чатах от вашего имени. Превращает команды `!btc`, `!gram`, `!balance`, `!gas`, `!top` и конвертер `!12 gram azn` в стильные графические карточки с реальными иконками криптовалют и курсами мировых валют!

---

## 🌟 Как это работает

1. **Официальный Telegram Business:** Бот создается в [@BotFather](https://t.me/BotFather) и подключается в настройках вашего личного Telegram-аккаунта (**Telegram Business ➜ Чат-боты**).
2. **Работа в личных чатах:** Когда вы (или собеседник) пишете команды в любом диалоге, Telegram пересылает обновление через официальный механизм `business_message`.
3. **Генерация фото-карточек:** Бот скачивает официальные векторные/растровые иконки криптовалют (BTC, TON, GRAM, ETH, SOL, USDT, BNB, DOGE, XRP и др.), строит 24-часовой сглаженный график цены и отправляет премиальную карточку в темной стилистике с подробной квотой.
4. **Мультивалютный конвертер с AZN и 35+ валютами:** Мгновенный пересчет любых сумм между криптой и фиатом (азербайджанский манат `AZN`, рубли `RUB`, доллары `USD`, евро `EUR`, тенге `KZT`, гривны `UAH`, дирхамы `AED`, лиры `TRY`, лари `GEL`, драмы `AMD`, сумы `UZS` и др.).
5. **Мониторинг комиссий сетей (`!gas`):** Отслеживание стоимости транзакций в реальном времени для блокчейнов TON, Bitcoin (Mempool) и Ethereum Mainnet.

## 🚀 Быстрая настройка (3 шага)

### Шаг 1. Создание бота в @BotFather
1. Откройте в Telegram бота [@BotFather](https://t.me/BotFather) и отправьте команду `/newbot`.
2. Придумайте имя и юзернейм (например, `MyCryptoBizBot`).
3. Скопируйте полученный **`BOT_TOKEN`** (вида `1234567890:ABCdef...`).
4. **ВАЖНО для бизнес-ботов:**
   - Отправьте в [@BotFather](https://t.me/BotFather) команду `/mybots`.
   - Выберите вашего бота ➜ **Bot Settings** ➜ **Telegram Business** ➜ **Turn On**.

### Шаг 2. Подключение бота к вашему аккаунту
1. В приложении Telegram (требуется Telegram Premium) перейдите в:
   **Настройки** ➜ **Telegram Business** ➜ **Чат-боты** (Chatbots).
2. В строке поиска введите юзернейм вашего бота (например, `@MyCryptoBizBot`).
3. Включите галочки:
   - ✅ **Отвечать на сообщения** (Reply to messages)
   - ✅ **Управлять сообщениями** (Manage messages / удаление триггеров)
   - В разделе *«Чаты»* выберите: **Все личные чаты** (или нужные вам).

### Шаг 3. Запуск бота
Запустите файл **`start_business_bot.bat`** (или в терминале):

```bash
cd telegram_business_bot
python -m pip install -r requirements.txt
python main.py
```

При первом запуске скрипт запросит ваш `BOT_TOKEN` и сохранит его в `.env`.

## 📋 Команды

### 1. В любых чатах (через Telegram Business):

| Команда | Русская версия | Что делает |
| :--- | :--- | :--- |
| `!btc`, `!gram`, `!ton`, `!eth`, `!sol` | `!биток`, `!эфир`, `!солана` | Фото-карточка с реальной иконкой, 24h графиком, хаями/лоями и ценой |
| `!12 gram azn`, `!12 gram to azn` | `!50 манат в руб`, `!100 azn to rub` | Конвертер в азербайджанские манаты `AZN` и другие мировые валюты |
| `!gas` | `!газ`, `!комиссия` | Фото-карточка с актуальными комиссиями сетей TON, Bitcoin и Ethereum |
| `!top` | `!топ`, `!рынок` | Сводка по топ-5 активам (BTC, ETH, TON, SOL, BNB) за 24 часа |
| `!balance` | `!баланс`, `!б` | Открывает баланс вашего кошелька по умолчанию |
| `!balance <адрес>` | `!баланс <адрес>` | Проверяет любой чужой кошелек (EQ..., UQ..., alice.ton, Tonviewer) |
| `!setwallet <адрес>` | `!кошелек <адрес>` | Сохраняет основной кошелек по умолчанию |
| `!tx [адрес]` | `!транзакции [адрес]` | Список последних транзакций с суммами и комментариями |
| `!ping` | `!пинг` | Замеряет отклик бота и время работы |
| `!help` | `!хелп`, `!помощь` | Меню всех команд в лаконичной цитате без лишних отступов |

### 2. В личных сообщениях с самим ботом:

- `/start` — панель управления с инлайн-кнопками:
  - 💎 **Баланс**
  - ⚙️ **Кошелек**
  - 👛 **Текущий адрес**
  - 💼 **Business статус**
  - ⚡ **Gas Fee (Комиссии)**
  - 📈 **Топ крипты**
  - 📖 **Команды**
- Любые запросы конвертации напрямую: `12 gram azn`, `10 btc usd`, `50 azn rub`, `100$ in azn`.
- Любые названия криптовалют: `btc`, `gram`, `ton`, `eth`, `sol` и др.

## 📁 Структура проекта

```text
telegram_business_bot/
├── card_generator.py       # Генератор 800x420 dark-карточек Pillow с реальными иконками
├── crypto_service.py       # API крипты (Binance, TonAPI), Mempool, ETH RPC и фиатных валют (35+)
├── formatter.py            # Лаконичные HTML-квоты (<tg-emoji>, фикс пустого места вверху blockquote)
├── handlers/
│   ├── business.py         # Обработчик Telegram Business сообщений
│   └── private.py          # Личные сообщения и инлайн-кнопки
├── icons/                  # Локальный кэш PNG иконок криптовалют (BTC, TON, GRAM, ETH, SOL...)
├── ton_service.py          # Интеграция с TonAPI (балансы, токены, операции, NFT)
├── ton_utils.py            # Парсинг и валидация UQ/EQ адресов
├── storage.py              # Локальное хранение сессий и кошельков (data.json)
├── config.py               # Настройки и переменные окружения
├── main.py                 # Точка запуска бота
└── requirements.txt        # aiogram, aiohttp, pillow, pydantic-settings
```
